# Experiments

This directory holds real tests of the Human-AI Workbench working method.

Do not create a general experiment framework in advance.

For each experiment, record only what is needed to answer:

1. What real project/task was being continued?
2. What context did the receiving AI get?
3. What did it do correctly, miss, repeat, or over-audit?
4. What coordination cost did the workbench add?
5. What should be kept, changed, or removed because of the observation?

Choose experiments from real work already worth doing. Do not invent a project merely to demonstrate the workbench.

Patterns belong in templates only after repeated use shows that they are worth standardizing.
